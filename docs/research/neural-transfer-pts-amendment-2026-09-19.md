**Pretraining amendment: correct media timestamps in Pixel features**

Before any candidate training, the DINO preparation exposed a frame-seeking failure in `recording-043`. Independent packet and sequential-decoding checks found all 77,459 frames, including the four that random seeking failed to decode. This is not missing footage.

The investigation found a larger issue. The existing AV extractor assigns visual timestamps using frame ordinal divided by average frame rate. That is inaccurate for this variable-frame-rate recording. At the nominal 1200-second feature tick, its selected frame actually has media PTS 1057.435056 seconds. DINO's random seeking instead returns a frame around PTS 1200.779422. Matching their saved timestamp arrays would therefore conceal different video content, and the AV features would still be misaligned with the manually reviewed source timeline.

Correct both representations before evaluating the new loss hypothesis. Generate fresh 104-channel AV and frozen-DINO features for all seven Pixel raw recordings using a regular 4 Hz media-time grid and the nearest decoded presentation timestamp, with earlier timestamps winning ties. Decode sequentially, track true frame ordinals independently, and verify selected PTS against the frame inventory. Feed the same selected frame to both visual representations. Preserve the feature formulas, DINO encoder/checkpoint, ROI and normalization. Align audio sampling explicitly to the media clock and record any stream-start offset. Preserve the old sources, caches, failed chunks, plans and diagnostics.

Only the seven coverage rows' audiovisual cache entries change; additional top-level provenance binds the original manifest and this amendment. The new DINO manifest binds the corrected representation, selected-frame/PTS identities and decoder repair sources explicitly.

Reuse only the six compact baseline cells for the exact and draft cohorts, whose complete training inputs remain unchanged. Retrain the reviewed-export compact baseline on corrected features.
