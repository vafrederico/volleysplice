# Streaming student full-panel inference

This additive orchestration preserves the unexecuted serial v1 queue and all registered model, feature, selection and numerical-auditor sources. It changes when already-authorized blind inference may start. The population stays 27 logical student tasks using 20 physical encoders, the frozen 42-source FP32 panel and all four temporal checkpoints. No new training, teacher extraction, calibration, selection or outcome metrics run here.

A physical owner's inference can append its source feature directory. Therefore it waits for both its own and every registered fit-reuse descendant's fit, numerical, fit-reuse where applicable, ordinary selection, correction and execution gates. Every logical task has its own prerequisite receipt. A reused inference target also waits for its owner's complete full-panel numerical inference audit. The queue then calls the unchanged per-task `infer_task` from the frozen reuse queue, which invokes the unchanged inference and numerical/reuse audit commands. All 27 tasks finish through the original v1 full-population completion gate.

The resource pilot measures batch-64 extraction only, with exact owner-cache parity. Its memory numbers do not bound the full temporal inference/auditing phase. Startup before each task requires at least 10GiB Linux available, 3GiB Windows physical free, 5GiB GPU free and 20GiB C: free. The new worker uses CPU2–3, two threads, nice10 and one image encoder at a time. Root must grant either a successfully exited predecessor slot or the independently verified quiescent pause described below. The grant binds same-boot process identities, the required exited descendants or stopped childless parent, and the active worker inventory. Total concurrency stays at most three long-lived GPU workers and two image workers. Temporary files, profiles and outputs remain on the NAS.

The queue uses no new hash cache or execution substitution. Incomplete fit families are skipped until their gates exist. Invalid or mutated gates fail closed. Source code, task membership, panel, resource qualification and tests are bound before execution. Registration is separate from launch; a root-issued slot authorization and execution grant are mandatory. The global freeze of all 162 selections still precedes every external accuracy evaluation.

As in v1's full preflight, one worker-local evidence dictionary is passed to the unchanged correction and closure validators. Their existing expected-hash and filesystem-stat checks still execute on access. No hash function is replaced, and no warm cache is persisted or imported. The final original-v1 completion gate starts its own fresh evidence dictionaries.

An explicit alternative authorization permits temporary replacement of the raw-inference slot while its known parent is quiescent. This is a pause, never an exit claim. The independent slot helper must prove the same boot/start/command identity, a live stopped process with no descendants, completed first three stages and an unlaunched fourth stage waiting for missing proxy prerequisites. The worker validates that proof at startup and again immediately before its first dispatch. Root may resume the raw queue only after the student's first-dispatch receipt (or verified termination) and successful completion of the separate nonstudent fitting slot. Later student tasks do not require raw to remain paused; the final lifecycle records the independently verified resume evidence. Root owns all process pause/resume actions.

After the interrupted agent session, a third explicit authorization mode permits recovery into a freshly allocated slot. It binds the root interruption observation and the preserved collection of predecessor process identities. The old exit status remains unknown: both the observation and the new grant must retain a null prior exit code, and the grant explicitly disclaims a successful prior exit. Every recorded predecessor must be absent at startup and immediately before first dispatch; the known fit, raw-inference parent, wrapper, and student worker IDs must all appear in the observation. The observation must belong to the current boot and bind the unchanged prior progress and identity records. This mode requires the same fresh active-worker inventory, resource floors and maximum concurrency as the other modes. Root's additive student-fit recovery grant supersedes the old execution-only image-worker exclusivity; model recipes and all scientific gates stay unchanged. A previously completed artifact is reused only through the unchanged validators, independently of the missing process exit status.
