# Lossless endpoint serialization in the independent selection audit

The ninth randomized selection exposed a representation mismatch in the frozen independent auditor. The selector attaches labels through a loader that casts interval endpoints to float; the auditor independently retained JSON integer endpoint types. Four values (`0`, `8`, `119`, `367`) therefore had different serialized gold hashes despite identical mathematical values, labels, ordering, timestamps, validity and ignored-time coverage. Root independently reproduced exactly those four differences in `selection-queue-v2/gold-serialization-independent-audit-v1.json`. The selection remains byte-for-byte unchanged, and the eight earlier passing gates remain intact.

An explicit execution adapter now loads the frozen selection auditor into an isolated Python module. It replaces only that module's `calibration_examples` binding with a wrapper around the original function. The wrapper casts rally and ignored-interval start/end fields to float only when exact rational equality holds before and after the cast. It performs no clipping, merging, label revision, mask change or other transformation. It checks all other function bindings before and after execution. The historical original-corpus branch is never adapted.

The frozen audit body executes all its ownership, metric, candidate and strict-floor checks against the unchanged selection artifact. Its base receipt is retained. A separate independent gate reconstructs the original data in a fresh, unmodified auditor module and verifies the complete before/after gold documents, exact field differences, rational equality, registered source scope, and unchanged selection hash. A nonrepresentable integer, another function replacement, another field/value/type/order change, missing proof, or stale reference fails. Zero-difference adaptations receive the same proof and gate.

For compatibility with frozen consumers, the published ordinary gate retains `auditor` as the identity of the delegated frozen body. `executionAuditor`, `executionAdapter` and `executionScope` prominently identify the actual execution, the sole replaced symbol, bound amendment, before/after proof, retained base receipt and independent serialization gate. Publication cannot use this compatibility field alone. A base receipt stripped of its required adapter declaration is rejected by reconstructing unmodified gold and checking its serialized hash.

The independently audited recall-containment correction remains unchanged. Both its ordinary and companion gates are still required. All new entry points are in `scripts/generalization-selection-serialization.py`:

- `audit-selection --plan PLAN --selection SELECTION --output ORDINARY_AUDIT` runs the explicitly adapted ordinary audit and its independent serialization gate.
- `freeze-selections --plan PLAN --registration ORIGINAL --registration RANDOMIZED --registration PROXY --output GLOBAL_GATE` requires all 162 selections and every applicable gate. The order matches the original containment amendment's registrations.
- `evaluate` requires all original arguments, `--correction-audit`, and `--global-selection-gate`. It records the global freeze before delegating numerical evaluation and publishes a separate result-publication receipt. No additional-video outcome metrics may be opened before the complete global freeze, even if a task's own inference is finished.
- `audit-results` requires `--global-selection-gate`, every one of the 270 result-publication receipts, and every applicable serialization gate before delegating the existing complete result audits unchanged.
- `report --index INDEX --audit JOINT_AUDIT --output REPORT` requires the combined gates before the existing report builder runs. The original containment workflow's `bind-index` still adds its immutable plan metadata.

Raw label-blind inference and production raw replay may overlap remaining fitting after the required per-task selection gates. Production metric evaluation also waits for the same global 162-task freeze. CPU coordinators retain NAS-only artifacts and one selection worker; this amendment adds no fitting or GPU work.
