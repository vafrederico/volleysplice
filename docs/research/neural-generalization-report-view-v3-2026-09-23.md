# Matched variant comparison view

The separately named v3 renderer adds a model filter and two presentation modes. The existing single-scenario view compares models, including the separate historical nested context. The variant view selects one model, one draw or already-saved complete-draw mean, and one embedding precision. Six checkboxes expose original-medium, expanded-medium, expanded-large, expanded-wide-validation, export-rally-training and export-rally-selection together. Entering this view defaults to the reserved common-unseen panel; padding, label policy and production-exposure filters remain shared.

The view copies existing rows only. It does not pool recordings, average draws, select thresholds or synthesize missing variants. Missing saved rows are named explicitly. Infeasible or incomplete means remain visible gaps with no fabricated zero. A source-scope mismatch warning includes incomplete rows and prevents treating a mixed population as a matched comparison. Production remains a fixed comparator and is shown only when its recording scope and panel/policy/exposure/padding match a displayed neural scope. Historical results cannot enter the variant mode.

The adapter imports and hash-checks the frozen v2 renderer. Its columnar transport and embedded exact-source JSON.gz blocks remain byte-for-byte identical; the existing audit digest and original JSON download contracts are unchanged. Only active view rows become browser objects. The v1 and v2 renderer and QA sources are preserved.

A synthetic fixture with 2,211 rows passed exact packed-series reconstruction and compressed-download byte equality. A bounded offline Chrome run verified the model filter, all six variants, a single draw/precision, matched production overlay, an incomplete mean gap, mismatched sources, missing variant rows, variant toggles and separate historical mode. It opened no external page requests and produced no browser errors. Profile/cache/temp/download/screenshot artifacts stayed under the NAS `html-variant-qa-v1` directory. These invented values are visibly marked as synthetic and are never published as model results. Full report visual QA remains pending audited final data.
